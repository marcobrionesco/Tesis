# Receta 08 — Cierre de sesión (obligatoria)

Al terminar cualquier sesión de trabajo:

1. `make pdf` — confirmar que compila. Si no compila, anotarlo como bloqueo.
2. Actualizar `00_proyecto/ESTADO.md`: estado de capítulos, próximos pasos, bloqueos, fecha.
3. Agregar entrada al inicio de `00_proyecto/BITACORA.md` (quién, qué se hizo, qué quedó pendiente, archivos tocados).
4. Si se tomó una decisión relevante, agregarla a `00_proyecto/DECISIONES.md`.
5. Si aparecieron términos o símbolos nuevos, agregarlos a `00_proyecto/GLOSARIO.md`.
6. Commit con mensaje descriptivo en español y push:
   `git add -A && git commit -m "Cap. 2: sección de normativa reescrita" && git push`
