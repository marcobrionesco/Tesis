# Introducción y Planteamiento del Problema

### Título de sección 

Para los títulos de secciones, utilice el estilo de este documento que se denomina “título 3”. El estilo “Título 1”, se usará para los nombres de Capítulos y el estilo “Título 2”, para los nombres de secciones previos al primer capítulo.


##### Título de subsección 

Para los títulos de subsecciones utilice el estilo “Título 5” definido en este documento.


### Figuras y Tablas

Las figuras y tablas deben estar numeradas en forma independiente, con fuente Times New Roman tamaño 11. Para la numeración de figuras y tablas se emplearán dos números: el primer número para indicar el capítulo al que pertenece la figura o tabla y el segundo para indicar el correlativo dentro de la sección. Por ejemplo, “Figura 4.3” refiere a la figura número 3 de la sección 4. Las tablas y figuras deben referenciarse en el texto antes de que aparezcan y no después. Además, éstas deben ubicarse lo más cerca posible de su referencia (“…como se ve en la tabla 5.12.”). Se debe indicar además del número, a qué figura o tabla corresponde (“Figura 2.2: Modelo Conceptual del Sistema”).

Por ejemplo, en la Tabla 1.1 se muestran las propiedades mecánicas de los materiales más usados en ingeniería.

## Anexo I: Cálculo de curva elástica para geometría de inercia constante

### I.1. Método de doble integración

Aplicando el método de doble integración, para el tramo 0≤ x ≤ x<sub>inf</sub> se tiene:

$$\frac{d^{2}\upsilon_{1}}{{dx}^{2}} = \frac{- M + FL - Fx}{EI}$$

$$\frac{{d\upsilon}_{1}}{dx} = \frac{1}{EI}\left( - Mx + FLx - \frac{Fx^{2}}{2} + C_{1} \right)$$

$$\upsilon_{1} = \frac{1}{EI}\left( - \frac{{Mx}^{2}}{2} + \frac{{FLx}^{2}}{2} - \frac{Fx^{3}}{6} + C_{1}x + C_{2} \right)$$

Para el tramo x<sub>inf</sub> ≤ x ≤ L:

$$\frac{d^{2}\upsilon_{2}}{{dx}^{2}} = \frac{M - FL + Fx}{EI}$$

$$\frac{{d\upsilon}_{2}}{dx} = \frac{1}{EI}\left( Mx - FLx + \frac{Fx^{2}}{2} + C_{3} \right)$$

$$\upsilon_{2} = \frac{1}{EI}\left( \frac{{Mx}^{2}}{2} - \frac{{FLx}^{2}}{2} + \frac{Fx^{3}}{6} + C_{3}x + C_{4} \right)$$
