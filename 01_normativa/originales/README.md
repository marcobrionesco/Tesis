# Originales de la normativa

Sube aquí, **sin modificar**, todo lo que te dio la universidad:

- Reglamento de memoria/tesis
- Guía o manual de formato
- Plantillas oficiales (Word/LaTeX)
- Ejemplos de portada, logos
- Correos con instrucciones del profesor guía (puedes pegarlos como `.md`)

Nombrar así: `AAAA-MM-DD_origen_descripcion.ext`
Ej.: `2026-03-10_facultad_guia-formato-memorias.pdf`

Después de subirlos, pide a la IA: *"aplica la receta 01_extraer_normativa"*.
